# Copys de Naturaleza de Reta

Esta carpeta documenta los textos que actualmente aparecen en las páginas HTML. Los archivos Markdown son la fuente de referencia editorial para futuras actualizaciones, pero no se cargan en el sitio: cualquier cambio de copy debe actualizar también el HTML correspondiente.

## Estructura

- [global.md](./global.md): textos compartidos de navegación, pie de página y controles.
- [paginas/inicio.md](./paginas/inicio.md): landing page.
- [paginas/ambientes.md](./paginas/ambientes.md): página índice de ambientes.
- [paginas/biodiversidad.md](./paginas/biodiversidad.md): página general de biodiversidad.
- [paginas/conservacion.md](./paginas/conservacion.md): página de conservación.
- [paginas/proyecto.md](./paginas/proyecto.md): página institucional del proyecto.
- [paginas/sumate.md](./paginas/sumate.md): página de participación.
- [paginas/animales.md](./paginas/animales.md) y [paginas/plantas.md](./paginas/plantas.md): subsecciones y buscadores de biodiversidad.
- [ambientes/](./ambientes/): contenidos de ambientes y destinos del Río, identificados actualmente mediante anclas dentro de `ambientes.html`.
- [biodiversidad/animales/](./biodiversidad/animales/) y [biodiversidad/plantas/](./biodiversidad/plantas/): textos de las fichas individuales.

## Criterio de transcripción

Los textos se copiaron del HTML y de los datos que `biodiversidad.js` muestra en los modales. Se conserva la redacción, puntuación, orden de aparición, placeholders y estados funcionales actuales. Las rutas indicadas son las que existen en el sitio; las fichas de ambientes no se presentan como archivos HTML independientes.

En cada ficha se separan el texto visible, los datos del modal y los textos alternativos o placeholders para facilitar su mantenimiento sin confundirlos con el contenido principal.
